MyOOPProjects
📌 About the Project

MyOOPProjects is a collection of projects and exercises created to practice and demonstrate the main principles of Object-Oriented Programming (OOP).

The repository contains different examples and implementations designed to improve understanding of how OOP concepts are applied in real-world programming.

🧠 OOP Concepts

Throughout the projects, the following concepts are explored:

Classes and Objects
Encapsulation
Inheritance
Polymorphism
Abstraction
Constructors and Destructors
Interfaces
Composition and Aggregation
Exception Handling
Collections and Data Structures
